# Занятие 4. Model, ViewData, ViewBag, TempData

Продолжение проекта **Lesson1.WebServer**. Четыре способа передать данные на страницу и классические формы с редиректом.
Выводы и эксперименты по задачам — в [`notes.md`](notes.md).

## Как запустить
Rider → `AjaxLessons.slnx` → **Занятие 4** → **Lesson1.WebServer** → **Run**. Адрес: **http://localhost:5104**.

## Четыре механизма — где использованы

| Механизм | Где в проекте |
|---|---|
| **Model** (строго типизированный) | `TasksModel.InitialTasks`, `StatsModel.TotalCount/DoneCount/UndoneCount`, `AboutModel` |
| **ViewData** | `ViewData["Title"]` в каждом `.cshtml`, `ViewData["Description"]` в каждом `OnGet()` |
| **ViewBag** | Задача 2 (чтение того, что записано через ViewData), задача 6 (прототип `/Stats`, в истории git) |
| **TempData** | `TempData["Message"]` / `TempData["Error"]` после редиректа: добавление, удаление, ошибка, обновление статистики |
