# Занятие 7. Валидация данных: клиентская, серверная и собственные атрибуты

Продолжение проекта **Lesson1.WebServer**. Проверка данных на двух уровнях: **в браузере** (мгновенно, для удобства) и **на сервере** (обязательно, для защиты), для встроенных и собственных правил, в классических формах и в AJAX.
Подробные эксперименты и выводы — в [`notes.md`](notes.md).

## Как запустить
Rider → `AjaxLessons.slnx` → **Занятие 7** → **Lesson1.WebServer** → **Run**. Адрес: **http://localhost:5107**.

## Где какие правила

| Правило | Атрибут / код | Браузер | Сервер: Razor Pages | Сервер: API |
|---|---|---|---|---|
| Название обязательно | `[Required]` | ✅ unobtrusive | ✅ ModelState | ✅ TryValidateObject |
| 3–100 символов | `[StringLength(100, MinimumLength = 3)]` | ✅ unobtrusive | ✅ | ✅ |
| Без слова «тест» | `[NoForbiddenWords]` (свой) | ✅ ручной JS | ✅ | ✅ |
| Категория из списка | `[AllowedCategory]` (свой, занятие 6) | выбор из `<select>` | ✅ | ✅ |
| Пробелы по краям | `Trim()` + `IsNullOrWhiteSpace` | ✅ `trim()` в JS | ✅ | ✅ |
| Выполнена ⇒ есть название | `AddModelError("", ...)` | ✅ ручной JS | ✅ сводка | — |
| Срок не в прошлом | `[MustBeFutureOrToday]` (свой, ДЗ) | ❌ (сервер) | ✅ | ✅ |

## Задачи

| № | Задача | Где | Как проверить |
|---|---|---|---|
| 1 | Нет мгновенной обратной связи | `notes.md` | Пустое название → `POST /Tasks` и вся страница заново |
| 2 | Подключить unobtrusive | `_ValidationScriptsPartial.cshtml`, секции Scripts | View Source: `data-val-required` у полей |
| 3 | Мгновенная проверка | — | Пустое название → ошибка без запроса (Network пуст) |
| 4 | Минимум 3 символа | `TaskItem.Title` | «аб» → мгновенная ошибка, «абв» → отправка |
| 5 | Свой атрибут «тест» | `NoForbiddenWordsAttribute.cs` | Сервер отклоняет «Тестовая задача» |
| 6 | Свой атрибут не работает на клиенте | `notes.md`, `title-checks.js` | Было: POST уходит; стало: блокируется сразу |
| 7 | Minimal API не проверяет атрибуты | `POST /api/tasks` → `Validator.TryValidateObject` | `requests.http`: все неверные → 400 |
| 8 | Проверка перед AJAX | `findTitleProblem()` в обработчике кнопки | 0 запросов при ошибке; без проверки сервер всё равно 400 |
| 9 | Ошибка уровня модели | `EditModel.OnPostAsync`, `asp-validation-summary="All"` | Пустое название + «Выполнено» → общая ошибка |
| 10 | Пробелы | `Trim()` + повторная проверка | «   » и «  аб  » отклоняются везде |
| ДЗ | Срок не в прошлом | `DueDate`, `MustBeFutureOrTodayAttribute` | Вчера → ошибка, сегодня/будущее → ок |
